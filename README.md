# CraftSure Investor / Partner Demo

This repository contains the external-safe CraftSure investor and partner demo site.

CraftSure is an AI-assisted renovation intelligence platform for homeowners, contractors, and ecosystem partners. The public demo presents the product vision, market narrative, partner opportunity, and sanitized workflow only.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:5188`.

## Build

```bash
npm run build
```

## Public Boundary

This site is intentionally separated from the main CraftSure application. It does not publish protected product internals, private data, or operational implementation details.
